# DiscussionBridge for Hugo

Show Discourse discussions on a Hugo site and publish between Hugo and your
forum. The adapter prepares content and discussion data during the Hugo
build, so your site can be served as static files.

Use the [Hugo layouts](layouts/) to place discussions and the [Hugo
platform guide](https://docs.discussionbridge.dev/platform-profiles/) to plan the connection and build.
The [command reference](https://github.com/DiscussionBridge/hugo-discussion-bridge/blob/v0.4.0-alpha.1.hugo.4/README.md#native-commands)
covers the V4 publishing commands. [Hugo demo](https://hugo.demo.discussionbridge.dev/)
